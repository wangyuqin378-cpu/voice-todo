# 2026-09-17 · build28 开头口令与密钥检查

对象：随口清单 0.1.1 / build28，macOS 26 本机开发版。

本轮解决后台把普通工作指令误记成待办的问题。**固定口令已覆盖文字接收与应用入队；真人语音准确率和通知实际送达仍待验收，不能据此宣称没有问题。**

## 为什么会误收

旧入口把“新增”“添加”“安排”、日期和完成词当成接收意图。用户在其他应用里说“新增公开项目介绍”，也可能进入任务理解流程；等待追问期间，普通话语还可能被当成回答。

现在将接收授权与内容理解分开：

- 新增：开头说“提醒我…”或“帮我记录一下…”。
- 完成、取消、撤销、追问回答：开头说“清单，…”；完整应用名称也可明确寻址。
- 只在句中或句尾出现口令，不触发后台接收；普通话语不入库、不调用 AI、不弹窗。
- 手动输入、在清单里点击录音、独立录音按键仍可自然表达。
