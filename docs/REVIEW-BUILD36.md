# build36：完成与取消后的提醒同步

日期：2026-09-18。状态：本机开发版已安装；不构成真人语音或通知实际显示验收。

## 问题与修复

系统正在读取通知或提交提醒时，用户可能完成、取消事项或关闭提醒。旧流程仍使用之前的任务快照，会短暂提交已经失效的提醒，或等下一轮系统查询才撤回。手动操作还有一处额外等待：提醒同步排在界面的权限刷新之后。

现在任务变化会直接进入提醒同步，权限显示独立刷新。已知失效提醒立即请求移除；每次异步查询后检查是否已有新任务状态，过期流程停止。已在提交中的失效提醒，提交返回后先撤回再继续查询。调度记录只保留最新清单仍有效的提醒；完成后立即撤销时，按最终状态恢复。

这是减少误提醒窗口的修复。macOS 在取消前已显示的提醒无法收回用户已经看到的内容，系统接口调用成功也不证明通知已实际显示。
