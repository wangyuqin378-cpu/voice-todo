# build35：自定义语音按键

日期：2026-09-18。状态：本机开发版已安装，源码同步；尚不构成完整设备 / 外部输入法验收。

## 改动

设置新增「录入按键」和「恢复 Fn」。默认保留 Fn，可以录入单个左右修饰键、功能键、普通键，以及带修饰键的组合。两条共享语音路径（本机识别 / 接收输入法文字）共用配置。按键设置不会修改第三方语音工具，用户需选用原工具的相同快捷键。

录入期间暂停语音接收，在设置面板消费按键，避免误录音或执行应用菜单命令。完全松开后可以保存；Esc 取消，切出面板清除未完成的录入。普通运行继续被动监听，不消费原工具的快捷键。设置、录音状态、接收提示和追问提示显示实际配置。

完整组合按下才开始，第一次释放结束本次按住；多余键、Esc、配置切换及睡眠重置丢弃会话。修饰键先释放不会导致重复开始。自动重复按键不能在重置 / 取消设置后重新开始。默认 Fn 的原有组合键取消规则保持不变。

限制：Esc 保留作取消；Caps Lock、两个普通键组成的组合不支持；系统保留快捷键、硬件媒体键或被其他程序截走的事件不能保证收到。单独字母可能在普通打字时触发。
