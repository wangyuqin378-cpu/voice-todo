# 2026-09-17 审阅与验证

对象：随口清单 0.1.1 / build27，macOS 26，本机开发版。

结论：本轮复现的问题已修复，可将源码保存到私有开发仓库。**尚未达到公开稳定版或完整真人语音验收标准。** 单元测试、文字到动作验收、界面观察和实际通知送达分别记录，不相互替代。

## 本轮发现与处理

| 优先级 | 发现的问题 | 处理与验证 |
| --- | --- | --- |
| 高 | 60 条远期通知占满队列，新加入的紧急事项排不进去 | 每次核对重新选择最近 60 条；模拟通知中心验证紧急事项替换最远项且不重复提交 |
| 高 | 权限关闭时，消失的通知请求可能被记成已送达 | 关闭权限不推断送达，清理调度记账；恢复权限后可补发，重启去重有测试 |
| 高 | AI 截取前半句完成表述，忽略后面的“还没交” | 校验后续同一对象或省略对象的否定；矛盾时不勾选，保留原话 |
| 高 | 无依据的 AI 撤销、补记无关完成记录，或用“选择任务”文字冒充取消按钮点击 | 撤销必须有完整指令；补记必须对应原话；取消选择核验真实按钮参数或明确序号 |
| 中 | “提前 48 小时”被缩成一天 | 明确提前量保留；仅默认偏好的可配置范围有限制；增加跨日校验 |
| 中 | 指定“10月1号”取消、不完整的“报销提交好了”等表达失败 | 支持完整年月日取消；部分名称进入候选追问，不自动勾选 |
| 中 | 常见完成语序和改口理解失败 | 支持“给妈妈的电话打完了”等词序；保留收件人、对象等区分词；改口省略对象需前文明确指向 |
| 中 | 只说“记一下”，AI 擅自设置提醒 | 应用检查当前输入或正在回答的问题中是否存在提醒语境，不让模型自行增加通知 |
| 中 | 混合输入里的“不用提醒”压掉另一件事项的追问 | 按事项处理需要补时间的状态；增加混合输入回归 |
| 中 | “清单，明天下午三点”补充时间被当作修改旧任务而拦截 | 去掉称呼后判断回答；只允许补齐当前新建事项的问题，不能语音修改已有事项 |
| 中 | 新安装默认启用不稳定的输入法文字接收模式 | 默认 Fn 本机识别；保留已有用户明确选择的模式 |
| 中 | AI 设置没有完整说明会发送哪些任务数据 | 设置中补充本次文字、任务名称、日期、完成状态的发送范围；录音不上传 |
| 中 | 旧验收集还期待“记得报销”必追问、到时提醒；仅核对提醒未核对事项日期 | 按已确定的产品规则更新期望，同时核对事项日期、时间精度、提醒和完整单条记录 |

## 验证结果

- 离线测试：260 项中 **255 项通过、5 项显式联网测试跳过、0 失败**。
- 另行启用真实已配置模型：**5 组对话测试通过**，包含新增不合并、午夜相对日期、严格完成、否定、混合指令、追问、撤销、句尾提醒和提前量。
- 36 条合成中文文字：**36/36 字段验收通过，误完成 0**；12 条由本机规则处理、24 条调用 AI。本轮文字处理耗时中位数 0.54 秒、最长 1.39 秒，**不包含录音、转写或桌面接收耗时，不是泛化准确率**。
- 首轮 36 条有 2 条失败：部分名称未进入追问、无提醒要求却新增通知；修复后重跑通过。保留失败记录，没有用降低预期掩盖问题。
- 发布构建与本机签名验证通过，更新复用原签名身份；已安装并启动 build27，原有待办、已完成和未处理记录保持原状。应用内 AI 连接检查成功。
- UI 实际查看：清单、设置、未处理恢复、手动编辑表单。界面截图包含私人记录，仅存本机，不进入仓库。
- 发布前检查：仅提交源代码、测试、合成用例、资源、构建脚本与文档；真实清单、原话、截图、日志、API Key 和签名私钥均排除。

## 仍需通过的设备验收

1. 在浏览器、编辑器、全屏应用分别实际按 Fn：按一下开始 / 再按结束，按住 / 松开，Esc 取消，组合键不触发事项；确认不会卡录音。
2. 用真实麦克风说至少 30 条日常中文，包含同名任务、否定、改口、取消和句尾提醒。记录原话、转写、最终任务与总延迟；明确表达无需修正至少 90%，误完成为零。
3. 实际等待系统通知出现，覆盖后台、退出 / 重启、睡眠唤醒和关闭 / 重开通知权限。请求提交成功不算送达。
4. 与微信输入法、Typeless 同时占用 Fn / 麦克风时验证兼容。旧“接收输入法文字”模式仍为试验功能，有跨应用漏接风险。

## 已知设计边界

- 一次性提醒、本机存储；没有手机同步、重复事项或团队功能。
- 通知队列最多优先放最近 60 条；更多事项需要应用持续运行以补充。
- 权限允许时，到时且消失的系统请求会记为已处理，以避免用户清除通知后重复补发；无法完全区分系统丢弃和用户清除。这是目前的送达观测限制。
- 本机匹配有意保守；复杂或不完整的名称可能要求补充或手动选择。真实 AI 的输出仍可能被校验拦截并保留为未处理。
- 本机开发签名不等于 Apple 公证；仓库不提供可面向公众承诺安装兼容性的稳定发行包。
