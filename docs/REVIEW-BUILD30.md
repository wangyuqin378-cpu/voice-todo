# build30：自然表达与无 AI 使用

日期：2026-09-17。版本：0.1.1 / build30。

## 本次变化

- 取消后台接收的固定开头要求。个人安排、句中 / 句尾提醒、完成、取消与撤销均可进入理解流程；普通闲聊、引用示例与孤立词尽量忽略。短回答需有效的同来源追问上下文。
- 已配置 Key 时优先调用 AI；无 Key、服务故障或模型动作未通过校验时尝试本机规则。没有支持的解释则保留原话，可修改、重试或手动添加，不再以配置 AI 为门槛。
- 本机支持简单混合事项与补记完成。整段在副本上校验后提交，否定或改口不执行半段；完成、取消继续核对完整名称、日期、状态和候选。
- 未处理记录增加手动添加入口，显示原话供整理；源记录保留至用户忽略，避免长文本只整理一件就丢失其他内容。旧版缺 Key 的提示改为当前可用的恢复方式。
- 沿用 build29 的通知标题同步修复；本次不更改底层语音采集或系统通知机制。

## 已验证

1. 离线套件：278 项中 273 项通过，5 项显式联网测试默认跳过，零失败。新测试用独立内存仓库与空 Key，确认完全不请求 AI；覆盖创建、完成、重复完成、取消、撤销、提醒与提前量、混合输入、补记完成、无口令追问和未处理记录手动恢复。
2. 注入模型测试：配置 Key 时简单表达也先走 AI；模拟断网回退本机规则；模型错误地完成相似任务时被校验拒绝，转为选择具体事项。测试使用假凭据，不读取日常 Key。
3. 真实 AI：显式运行 5 组、共 31 句合成输入，全部断言通过。包括相对日期、同名新增、相似完成、改口、否定、多轮追问、混合指令、句尾提醒和提前量。全部使用合成清单，不是麦克风端到端测试。
4. 最后 5 个真实模型请求耗时约 0.60–1.17 秒；该数值只代表该次文字请求，不包含录音 / 转写 / 桌面通知。
5. 发布前扫描当前文件及可达 Git 历史 119 个文件对象，未发现常见 API Key、GitHub Token 或私钥模式。Key 不随应用分发；扫描结果不构成绝对无秘密的证明。

## 仍需真人验证

自然表达覆盖并不等于任意一句话都能正确理解。AI 也可能遗漏、误解或被本机校验拒绝，不能据此承诺 100% 准确。

需要继续由真实设备验证物理 Fn → 转写 → 创建 / 完成、第三方语音工具接收、全屏 / 睡眠 / 唤醒、通知实际送达及真人 30 句准确率与总延迟。测试通过、应用启动和通知接口调用均不能替代这些检查。

此前留下的通知验收事项已经撤销，本次没有把那次未观察到的通知当成已送达。已有用户事项与原始失败记录保留。
