# 随口清单

想到了说一句，做完了也说一句。一个个人使用的 macOS 菜单栏待办工具。

> 当前为 **0.1.1 / build27 开发版**。源码和本机安装可用；不代表已经通过完整的真人语音、全屏环境或通知送达验收。审阅结果见 [审阅与验证](docs/REVIEW.md)。

## 日常使用

轻按 **Fn** 开始，再按一次结束；也可以按住说话、松开结束。Esc 取消。普通话语不弹窗、不保存；识别到事项操作后显示结果和撤销入口。菜单栏可以打开清单。

| 表达 | 行为 |
| --- | --- |
| 提醒我明天下午一点面试 | 新建面试，事项时间 13:00，默认 12:50 提醒 |
| 我10月1号要买车票，提醒我一下 | 新建买车票，只给日期时默认当天 09:00 提醒 |
| 明天下午一点面试，提前半小时提醒我 | 12:30 提醒；明确提前量优先于默认设置 |
| 后天下午一点面试，明天下午三点提醒我 | 保存两个独立时间，创建一件事项 |
| 我明天有个面试 / 记得报销 | 只记下事项，不自动提醒 |
| 材料交好了 | 名称完整对应且唯一时完成“交材料” |
| 帮我取消明天下午六点的面试 | 唯一匹配标题和事项时间时取消，可撤销 |
| 撤销 | 撤销最近一次清单操作，包括相应提醒 |

- **新增不合并**：同名事项也新增，不擅自修改旧任务。语音修改旧日期、标题或提醒会引导手动编辑。
- **完成要对应**：仅说“材料交了”不能自动完成“交签证材料”；有相似或同名事项会追问。没有原事项且完成内容明确时可以补记完成。
- **提醒可配置**：设置 →“有具体时间时”，支持提前 5、10、15、30、60 分钟或到时提醒；仅对新事项生效。已进入提前窗口时立即安排提醒。
- **追问不丢失**：要求提醒但时间不足时先保存，再问时间；可继续用 Fn 回答“不用提醒”或具体时间，问题也能从列表继续。
- **手动处理**：待办 / 已完成、搜索、勾选、恢复，以及每行“…”中的编辑、关闭提醒、取消事项。文本框支持长文本，⌘ Return 处理；草稿会保留。
- **失败恢复**：断网、解析或校验失败时保留为“未处理记录”。重试沿用原说话日期和时区；修改后以本次提交时间理解相对日期。原输入不会重复执行。

## 语音入口

新安装默认 **Fn · 本机识别**：随口清单在 Fn 期间独立使用 Apple SpeechAnalyzer 识别中文，不依赖其他输入法提供转写接口，也不会删除或发送其他应用的文字。与微信输入法、Typeless 等同时录音时的兼容性需要在实际设备验证。

设置 →“语音入口与诊断”可切换：

- Fn · 本机识别（默认）；普通转写保持安静。
- 独立录音按键：右侧 Option / Control / Command，或列表中的录音按钮。
- Fn · 接收输入法文字（试验）：依赖辅助功能与本次转写接收，存在跨应用漏接情况，不作为可靠性承诺。

麦克风只在主动录音时使用；单次最多 90 秒，取消或收尾后停止。不持久保存录音。Fn 组合键不会执行事项；具体键盘与全屏应用仍需真人验证。

## 首次运行

要求 **macOS 26、Swift 6.2 / Xcode 26**，以及设备支持并安装简体中文 SpeechAnalyzer 模型。

1. 在设置中允许麦克风和输入监控；需要通知时允许系统通知。
2. 检查 / 安装中文模型，体验一次开始与结束录音。
3. 简单表达优先本机处理。复杂表达需要配置兼容的 AI 接口和 API Key，默认阿里云百炼 `qwen-flash`；接口地址、模型可更换。

没有注册、订阅或自建服务端。本仓库不附带 API Key。

## 构建与测试

```sh
swift test
zsh scripts/build-app.sh
open 'dist/随口清单.app'
```

如果系统没有选择完整 Xcode，可在命令前指定 `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`。

构建脚本创建并复用项目专用开发签名，文件放在被忽略的 `.local-signing/`。保留此目录可避免每次更新更换签名；不要上传或分享它。可通过 `CODE_SIGN_IDENTITY` 指定自己的签名身份。此签名只用于本机开发，**不是公证后的公开分发包**。

默认测试不联网、不打开个人任务库。联网验收为显式选择，会使用已配置服务并产生其调用费用：

```sh
VOICETODO_LIVE_QA=1 swift test --filter LiveConversationTests
'dist/随口清单.app/Contents/MacOS/VoiceTodo' --evaluate qa/cases.json /tmp/voice-todo-evaluation.json
```

验收使用合成任务，不写入日常清单。第二条命令验证本机规则与真实 AI 的文字处理，不包含麦克风或通知送达。预期用例同时核对事项日期和提醒时间，禁止将不同任务的字段拼成“通过”。

## 数据与隐私

- 任务、原话、追问、失败记录和最近 30 次撤销保存在 `~/Library/Application Support/VoiceTodo/`。偏好与未提交草稿在应用的 macOS 偏好设置中。
- 本机规则命中的操作不调用 AI。需要 AI 时，会发送当前文字、清单中的标题 / 日期 / 完成状态及必要追问上下文到你配置的服务；原始录音不上传。完整索引过大时明确失败，不假装“没有找到”。
- 手动填写的密钥保存在系统钥匙串。可显式引用本地 DeepSeek 配置，但该密钥仅允许用于官方 DeepSeek 接口；不会将密钥写入源码或任务日志。
- 诊断仅保留有限的接收阶段、时间和应用标识，不记录转写、任务标题、其他键盘输入或剪贴板内容。
- 备份时先退出应用，再复制整个数据目录，包含 `.store` 的附属文件。恢复旧备份会覆盖备份后的任务，需自行核对。

## 提醒的实际边界

完成或取消会移除对应系统提醒；撤销完成 / 取消时重新安排。已过期的恢复事项会补一次提醒。通知权限关闭时不会声称提醒已生效，重新开启后会核对遗漏。

系统队列优先放最近的 60 条，新增紧急事项会替换排在后面的提醒。超过此数量时需要应用持续运行以补充队列。关闭应用后，已经交给系统的提醒仍由 macOS 管理；专注模式、睡眠、锁屏和系统显示设置可能影响用户看见通知。

为避免用户清除通知后反复弹出，权限允许期间已到时且消失的系统请求会按已处理记账。这无法完全区分系统丢弃与用户清除，**不能当作实际送达证明**。

更多实现说明见 [架构](docs/ARCHITECTURE.md)。
