# 随口清单

[English](README.md) · [完整使用指南](docs/USAGE.md)

## 这是什么

随口清单是一款 **Mac 菜单栏待办工具**：说一句记下事情，做完后再说一句，就能完成对应事项。它支持中文日期理解、按需设置一次性提醒、手动管理和撤销，清单保存在本机。

**当前源码为 0.1.1 / build36 开发版，仅支持 macOS 26。** 尚无 Windows / Linux 客户端或公证后的通用安装包；直接接收其他语音产品的转写仍在试验。

## 怎么使用

### 构建并打开

需要 macOS 26、完整 Xcode 26 / Swift 6.2。本机语音识别还需要设备支持并安装简体中文 SpeechAnalyzer 模型。

```sh
git clone https://github.com/wangyuqin378-cpu/voice-todo.git
cd voice-todo
zsh scripts/build-app.sh
open 'dist/随口清单.app'
```

脚本会创建本机开发签名，不等于 Apple 公证。Xcode 不在默认位置时，见[构建与签名说明](docs/DEVELOPMENT.md)。

### 先试一件事

1. 打开设置，为默认的 **Fn · 本机识别** 模式允许输入监控和麦克风权限；需要提醒时，再允许通知。
2. 轻按 Fn 开始，说 **“提醒我明天下午三点面试。”**，再按 Fn 结束。也支持按住说话、松开结束，Esc 取消。
3. 查看清单：「面试」的事项时间应为明天 15:00；默认提前 10 分钟，即 14:50 提醒。
4. 做完后说 **“面试完成了。”**，名称对应且目标唯一时完成事项；说 **“撤销。”** 可以恢复。也可以直接在清单里输入文字或手动操作。

**无需固定开头。** 个人安排、提醒、完成和取消都可以自然表达：“明天下午三点面试”“我10月1号要买车票，提醒我一下”“材料交好了”。提醒放在句尾也可以；普通聊天保持安静，含糊的内容可能需要追问或手动核对。

以上是使用示例。文字到动作已有测试；真人语音、与其他语音输入工具同时使用、通知实际送达仍需设备验收。语音接收失败时可先用文字输入，具体排查见[使用指南](docs/USAGE.md)。

**AI 可选，不填 Key 也能用。** 简单提醒、明确的完成 / 取消及可确定拆分的多条事项直接在本机处理，不读 Key、不等网络。只有本机无法可靠理解时，才请求配置好的 AI；每次请求最多等待 8 秒，也可点「停止等待」，迟到的结果不会再改清单。仍无法理解的文字保留在「未处理记录」，可以修改或手动添加事项。AI 请求会发送当前文字、任务标题、日期、完成状态及必要追问上下文；应用不保存或上传原始录音，密钥存系统钥匙串，不随应用分发。[数据范围说明](docs/USAGE.md#数据与备份)。

## 为什么做

想起一件事，往往是在做另一件事的时候。再打开待办软件、找到输入框、整理一遍文字，很容易打断原来的思路。而事情做完后，记录“已完成”也应该和记下来一样方便。

随口清单想把这两步接在已有的语音输入习惯后面：想起来时说一句，做完时也说一句。默认按键为 Fn，可在设置 →「录入按键」改成原语音工具的按键或组合键。默认模式由本应用在本机识别；接收 Typeless 等外部工具的转写仍是试验功能，没有官方集成或完整兼容性认证。

简单事项先在本机处理，复杂表达才请求 AI，避免被慢模型拖住。build33 增加对假设和询问方案的检查：“如果我想住两天水屋呢，再帮我安排一下”保持安静；“我明天入住酒店”仍可记下。入口和写入前都检查完整原话，避免 AI 截取讨论中的片段创建任务。继续支持 Claude 与 OpenAI 兼容接口，不要求 flash 模型或固定开头；使用 AI 也不等于百分之百准确。

支持录入自定义语音按键，本机识别与接收输入法文字共用这个设置。录入时暂停接收，取消不改原设置，可一键恢复 Fn；系统保留快捷键和不同语音工具仍需实测。build36 修复完成或取消事项时的提醒同步延迟，避免旧调度继续提交已失效的提醒。
